C10 / RÈGLES

Supports

Règle commune, document, web : rayons, focus, survol, mouvement, densité.

Mêmes règles : Markdown · JSON · texte intégral

Règle commune. Palette, polices, logo et conventions ne se négocient pas d'un support à l'autre. Seules la mise en page et la densité s'adaptent. Si une règle de support contredit une règle de marque, c'est la règle de marque qui s'applique.

Document

Formats : DOCX, PDF. Format de page, marges, rythme vertical, onze styles nommés, types de page, tableaux, polices, diffusion. Règles complètes : section c12.
