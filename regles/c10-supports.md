# c10 — Supports

Règle commune, document, web : rayons, focus, survol, mouvement, densité.

> **Règle commune.** Palette, polices, logo et conventions ne se négocient pas d'un support à l'autre. Seules la mise en page et la densité s'adaptent. Si une règle de support contredit une règle de marque, c'est la règle de marque qui s'applique.

## Document

Formats : DOCX, PDF. Format de page, marges, rythme vertical, onze styles nommés, types de page, tableaux, polices, diffusion. Règles complètes : [section c12](c12-document.md).

## Web et interface

| Élément | Règle |
| :--- | :--- |
| Fond de page | #F6F6F6 |
| Rayons | 8 px petits éléments · 14 px cartes · 20 px blocs pleine largeur · 999 px boutons et étiquettes |
| Focus | Contour turquoise de 3 px, décalé de 3 px. Jamais supprimé. |
| Survol | Changement de couleur de bordure ou de fond, jamais de déplacement ni d'ombre portée : la charte ne prévoit aucune ombre. |
| Mouvement | Une seule animation : le remplissage des barres de graphique à l'entrée dans l'écran. Désactivée si le système le demande. |
| Densité — site | Marges généreuses, 17 px de corps |
| Densité — application | Densité maximale, 14 à 15 px |

Formes de contenu web : [section c13](c13-contenu-web.md). Interface d'application : [section c14](c14-interface.md).
