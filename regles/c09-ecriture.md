# c09 — Écriture

Conventions typographiques du français, ton de voix.

## Conventions

| Cas | Règle | Exemple |
| :--- | :--- | :--- |
| Symbole monétaire | Après le nombre, espace insécable | 166 250 $ |
| Pourcentage | Espace insécable avant le signe | 47 % |
| Séparateur de milliers | Espace fine insécable, jamais la virgule | 1 538 |
| Décimale | Virgule | 0,75 po |
| Guillemets | Guillemets français, avec espaces insécables | « ainsi » |
| Incise | Tiret cadratin, espacé | un choix — le bon — reste discutable |
| Heures | H majuscule, espace insécable | 860 H |
| Titres | Capitale à la première lettre seulement | Synthèse financière consolidée |
| Majuscules accentuées | Obligatoires, y compris en capitales | ÉCHÉANCIER |
| Sur-titres | Capitales, monospace, interlettrage ouvert | 05 / SYNTHÈSE |

## Caractères

Les exemples ci-dessus contiennent les caractères réels : les recopier tels quels.

| Caractère | Unicode | Emploi |
| :--- | :--- | :--- |
| Espace insécable | `U+00A0` | Avant $, % et H; à l'intérieur des guillemets français; entre un nombre et son unité. |
| Espace fine insécable | `U+202F` | Séparateur de milliers. |
| Guillemets français | `U+00AB / U+00BB` | Toute citation. |
| Tiret cadratin | `U+2014` | Incise, espacée. |

## Ton de voix

- Phrases courtes, verbes actifs, sujet nommé.
- Pas de superlatif sans chiffre derrière.
- Le vocabulaire du client, pas celui de la technologie.
- Dire ce qu'on ne fait pas est aussi utile que dire ce qu'on fait.
